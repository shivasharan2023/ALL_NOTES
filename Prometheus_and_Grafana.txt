# Introduction to prometheus
- Opensource monitoring solution
- capture metrics & alerting
- Time series data:identified by metric name & key/value pair : metric name (cpu usage)/label (system= 1)/sample (65%) 
- disk usage/system= 1/70%
- scrapped data stored in prometheus server
- PromQL (readonly language)
- Generate visualizations using built in expression browser or integrate with grafana
- written in Go language
- stores metrics in memory and local disk on an own custom, efficient format

# Architecture of Prometheus
- Prometheus server pulls data from various end points (IoT devices, client applications, or server where multiple applications are running ex. kubrnetes cluster)
- short lived jobs- push the metrics to pushgateway, prometheus pulls metrics from Pushgateway
- alert Manager- helps to send alerts based on the conditions set on the basis of monitoring
- Data Visualization & export: Prometheus  server-->PromQL-->Prometheus WebUI or Grafana or
- API clients can connect to Prometheus and run PromQL query and fetch the metrics

# Installation of Grafana
- Installing on windows
Installing Grafana on Windows

You can install Grafana on Windows using either the Windows installer or the standalone Windows binary. The default Grafana port is 3000, but you can change it if needed.

Method 1: Using the Windows Installer

Navigate to the Grafana download page.

Select the Grafana version you want (latest is selected by default).

Choose Enterprise or Open Source edition.

Click Windows and then Download the installer.

Open and run the downloaded installer.

Method 2: Using the Standalone Windows Binary

Navigate to the Grafana download page.

Select the desired Grafana version and edition.

Click Windows and then Download the zip file.

Right-click the downloaded file, select Properties, check Unblock, and click OK.

Extract the ZIP file to any folder.

Open the bin directory and run grafana-server.exe from the command line.

Optional: Change the Default Port

Open the conf directory and copy sample.ini to custom.ini.

Edit custom.ini and uncomment the http_port option.

Change the port to 8080 or another available port.

Running Grafana

Start Grafana by running grafana-server.exe from the bin directory.

Open your browser and go to http://localhost:3000/ (or your custom port).

Follow the on-screen Getting Started instructions.

Run as a Windows Service (Optional)

Download NSSM.

Use NSSM to add grafana-server.exe as a Windows service.

Default username:admin
Default password: admin

# Prometheus configuration
- configuration is stored in a yaml file format
- it can be changed and applied without having to restart prometheus
	- a reload can be done by executing kill-SIGHUP <pid>
- we can also pass parameters (flags) at stratup time to ./prometheus
- to scrape metrics need to add configuration to prometheus config file
- open prometheus.yaml file (contents as below0
-------------------------------------------------------
promethues.yaml
-------------------------------------------------------
# my global config
global:
  scrape_interval: 15s # Set the scrape interval to every 15 seconds. Default is every 1 minute.
  evaluation_interval: 15s # Evaluate rules every 15 seconds. The default is every 1 minute.
  # scrape_timeout is set to the global default (10s).

# Alertmanager configuration
alerting:
  alertmanagers:
    - static_configs:
        - targets:
          # - alertmanager:9093

# Load rules once and periodically evaluate them according to the global 'evaluation_interval'.
rule_files:
  # - "first_rules.yml"
  # - "second_rules.yml"

# A scrape configuration containing exactly one endpoint to scrape:
# Here it's Prometheus itself.
scrape_configs:
  # The job name is added as a label `job=<job_name>` to any timeseries scraped from this config.
  - job_name: "prometheus"

    # metrics_path defaults to '/metrics'
    # scheme defaults to 'http'.

    static_configs:
      - targets: ["localhost:9090"]
       # The label name is added as a label `label_name=<label_value>` to any timeseries scraped from this config.
        labels:
          app: "prometheus"
    scrape_native_histograms: true
----------------------------------------------------------------------
----------------------------------------------------------------------
